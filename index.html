Data & Privacy Notes

The distributed package contains encrypted resource data only. Plaintext consultant cost rates are never stored in the HTML, JavaScript, project JSON, or local browser storage.

Cost dataActual resource cost/hour is stored only inside the encrypted resource payload and decrypted in memory after the correct password is entered.
AuthenticationThis local prototype uses password-based encryption. A future SharePoint deployment can replace this with tenant authentication and server-side cost calculations.
Project filesUse “Save Project JSON” to create portable project files that can be reopened later.
